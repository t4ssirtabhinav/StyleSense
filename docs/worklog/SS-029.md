## Architect — 2026-07-29 (Opus, per model triage on raw `Risk: high`)

**Risk: high** — new DB migration with a deliberately policy-less RLS table (second `service_role`-only exception after `app_config`), and it is the free-tier revenue gate: an off-by-one or a reintroduced read-then-write lets a user spend past their ceiling with no error thrown. Full lane — stops here for human design review.

Design doc: `docs/tickets/SS-029-design.md`. Reuses SS-018's verified Upstash mechanism, changes only the unit (paise) and tier semantics. `IRateLimiter`/`ICostLedger` land in `backend/adapters/interfaces.py` alongside `IAppConfigRepository` — no new folder. **Reserve-then-reconcile**: one atomic `INCRBY` before the call, decision taken from its return value (never `GET`-then-`INCR`), reconciled after — the answer to the concurrent-burst boundary case, tested with real `asyncio` interleaving (§6.5). Money unit is integer micropaise (`cost_paise` survives as a generated column — plain `INTEGER` paise is unusable at sub-paise per-call cost). `fail_open` governs the infra-failure path only; paying-tier ceilings still enforced when Redis is healthy. Dated price table with `effective_until` + a `ledger_price_row_expired` assertion for the 2026-08-31 Sonnet pricing cliff.
