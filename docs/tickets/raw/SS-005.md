# SS-005 — Home Screen Shell + Bottom Tab Navigation

`[Feature]` `[P0]` `[Sprint 1]` `[1 pt]` Est: 5h
Depends on: SS-003

## Description

Build 5-tab bottom navigation (Home, Wardrobe, Style, Discover, Profile) with a custom tab bar styled to the design system. Tab bar: 64px height, warm off-white bg, marigold active icon, muted inactive, dot indicator below active icon.

Home screen (not just an empty state): greeting with user name, "What are you dressing for today?" heading with a horizontally scrollable occasion quick-select pill row (Office/Casual/Wedding/Festival/Date/Party), empty-state wardrobe nudge ("Add your first item" CTA), trending picks preview section (placeholder until Epic 6).

Other tabs: styled empty states with illustration placeholder, heading text, and muted subtext.

## Acceptance Criteria

- 5 tabs render: Home, Wardrobe, Style, Discover, Profile
- Active tab has marigold icon and dot indicator; inactive tabs are muted grey
- Tab bar is 64px with safe-area inset handling for notched/gesture-nav Android
- Home screen shows greeting, occasion pills (horizontally scrollable), wardrobe nudge
- Occasion pills: Office 💼, Casual ☀️, Wedding 💍, Festival 🪔, Date ❤️, Party 🎉
- Tapping an occasion pill navigates to the Style tab with that occasion pre-selected
- Deep link support for all tabs (e.g., `stylesense://wardrobe`)
- Each non-home tab shows a styled empty state

## Technical Notes

- Expo Router `(tabs)/_layout.tsx` with `screenOptions` for the custom tab bar
- Custom tab bar: haptic feedback on tap (`expo-haptics`), `useSafeAreaInsets()`
- Icons: `lucide-react-native` or `@expo/vector-icons` (Ionicons set)

## Edge Cases & Failure Modes

- Android 3-button nav vs. gesture nav: tab bar must not overlap system navigation
- Rapid tab switching: debounce tab presses to prevent double-navigation
- Portrait-lock: `orientation: 'portrait'` in `app.json`
