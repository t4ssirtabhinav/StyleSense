# SS-008 — Design System Foundation (UI Kit)

`[Task]` `[P1]` `[Sprint 1]` `[2 pts]` Est: 6h
Depends on: SS-001

## Description

Foundational design system as reusable React Native components styled with NativeWind. Every screen must use these — no raw `View`/`Text`/`TouchableOpacity` in feature code.

**Design tokens:** all colours (bg, accents, occasion colours, semantic), typography (Playfair Display, Poppins, DM Sans, JetBrains Mono, Noto Sans Devanagari), spacing (4/8/16/24/32/48), radii (8/12/16/24/pill).

**Components:** Button (primary/secondary/ghost/disabled + loading), Text (display/heading/body/caption/mono), Card (elevated/flat/outlined), Badge/Chip (occasion colour coding), Avatar, BottomSheet (`@gorhom/bottom-sheet`), Input (text/phone/OTP/search), IconButton, Skeleton (shimmer).

## Acceptance Criteria

- Design tokens file exports all colours, typography, spacing, radii from the architecture doc
- Button: 4 variants with correct colours and loading state
- Text: 5 variants with correct fonts
- Card: 3 variants with correct radii
- Badge/Chip: renders with occasion colour coding (4 occasion colours)
- BottomSheet: supports snap points (30%, 60%, 90%) with drag gesture
- Skeleton: shimmer animation matching card and list item shapes
- All components use NativeWind `className` — zero `StyleSheet.create` usage
- Storybook-style test screen showing all component variants

## Technical Notes

- NativeWind v4 with Tailwind config extended with custom colours
- Font loading: `expo-font` to preload all 5 typefaces in `_layout.tsx`
- BottomSheet: `@gorhom/bottom-sheet` (most reliable on Android across devices)
- Export from `components/ui/index.ts` for clean imports

## Edge Cases & Failure Modes

- Font loading failure: system font fallback, not blank screen; log to Sentry
- Long text in Badge/Chip: truncate with ellipsis at max 20 chars
- BottomSheet on Android: test on Samsung One UI, Xiaomi MIUI, and stock Android
