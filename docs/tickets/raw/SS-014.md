# SS-014 — Wardrobe Grid & Catalogue View

`[Feature]` `[P0]` `[Sprint 4]` `[2 pts]` Est: 6h
Depends on: SS-013, SS-008

## Description

A 2-column grid displaying all uploaded items. Must maintain 60fps with 100+ items on a Redmi Note 12. Sticky category filter row (All, Ethnic, Western, Footwear, Accessories, Favourites). FlashList grid: BG-removed image on a neutral card, category chip, wear count badge, favourite heart. Tap → BottomSheet with detail + actions.

Filtering by category (primary), occasion, season, colour. Search bar for text search across names, categories, brands. Sort: newest (default), most worn, least worn, cost per wear. Pull-to-refresh. Item count per category in filter badges. Empty state with "Add your first item" CTA. Free tier 50-item limit banner at 45 items.

## Acceptance Criteria

- 2-column grid renders with BG-removed item images on neutral card backgrounds
- Category filter pills filter in real-time (All, Ethnic, Western, Footwear, Accessories, Favourites)
- Item count shows per category in filter chips (e.g., "Ethnic (12)")
- Grid maintains 60fps scroll with 50+ items on mid-range Android (FlashList)
- Tapping an item opens a BottomSheet with full detail + edit/delete/mark worn/favourite actions
- Search filters across category, brand, and `user_notes`
- Sort works for: newest, most worn, least worn, cost per wear
- Pull-to-refresh fetches the latest items
- Empty state shows an illustration + "Add your first item" button
- Free tier shows a "50 items max" banner at 45 items

## Technical Notes

- `@shopify/flash-list` for a virtualised grid (faster than FlatList for image-heavy lists)
- `React.memo` on `ItemCard`; `expo-image` (not RN `Image`) for faster loading + caching
- Filter state in Zustand; server query in React Query with `staleTime: 5 minutes`
- Thumbnails (300px) in the grid, full image in the detail sheet

## Edge Cases & Failure Modes

- Items still processing (`bg_pending`): original image with a processing indicator overlay
- No items match the filter: "No items in this category" with an upload suggestion
- Image load failure (R2 CDN): placeholder with a retry icon
- Offline: cached items from React Query; disable upload with a "No connection" tooltip
