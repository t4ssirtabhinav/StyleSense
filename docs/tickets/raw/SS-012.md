# SS-012 — AI Auto-Tagging with Gemini Vision (India Taxonomy)

`[Feature]` `[P0]` `[Sprint 3]` `[2 pts]` Est: 6h
Depends on: SS-010

## Description

AI auto-tagging using Gemini 1.5 Flash with an India-specific fashion taxonomy prompt. The prompt enumerates all valid values for each field: the 20-value `wardrobe_category` enum (including `ethnic_kurta`, `ethnic_saree`, `footwear_ethnic` etc.), patterns, fabrics, occasions, seasons. Force JSON via `response_mime_type='application/json'`.

Validate the AI response with a Pydantic model: every field must match a valid enum. Confidence < 0.7 flags for user review. Cache the raw AI response in `wardrobe_items.ai_tags` JSONB and Upstash Redis (`tag:{image_hash}`, 30-day TTL).

## Acceptance Criteria

- Kurta image returns category `ethnic_kurta` with appropriate occasion tags
- Formal shoe returns `footwear_formal` with occasions (`office`, `formal_event`)
- Response includes `category`, `subcategory`, `color_primary` (hex), `color_secondary`, `pattern`, `fabric`, `occasion_tags[]`, `season_tags[]`, `confidence`
- All returned categories match the `wardrobe_category` ENUM exactly (Pydantic validated)
- Correctly identifies kurtas vs. western tops (>85% accuracy)
- Confidence < 0.7 items flagged for user review
- Cached in Upstash Redis; re-upload of the same image returns the cached result
- Gemini rate limit (15 RPM free) respected; excess queued, not dropped
- Response time under 3s (Flash model)

## Technical Notes

- Gemini: `google-generativeai` Python SDK with `response_mime_type='application/json'`
- Cache key: MD5 hash of compressed image bytes (not URL)
- Implement a semaphore/queue for concurrent uploads to stay within 15 RPM
- Follow CLAUDE.md's hexagonal pattern: define `IVisionProvider` in `ai/ports/interfaces.py` (this repo's first vision-domain port — `IStylingProvider` already exists from SS-006), implement `GeminiVisionAdapter` in `ai/adapters/`, router depends on the port via `Depends()`, never on the adapter directly

## Edge Cases & Failure Modes

- Not clothing (food, pet): return `{ category: null, confidence: 0.0 }`; show "Doesn't look like clothing"
- Ambiguous Indo-Western fusion: present top-2 options for the user to pick
- Accessories alongside clothing: focus on the primary/largest item
- Saree vs. dupatta disambiguation: prompt includes size/context clues
- Multiple items in one photo: tag the dominant/largest item only
